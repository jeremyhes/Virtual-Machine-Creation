<h1>Virtual Machine Creation</h1>



<h2>Description</h2>
Project consists of a simple step by step tutorial of creating a Virual Machine
<br />

<h2>Environments Used </h2>

- <b>Windows 11</b>

<h2>Program walk-through:</h2>

<p align="center">
Go to the VMware website and click "download now": <br/>
<img src="https://imgur.com/wVeijlz.png" height="80%" width="80%" alt="Virtual Machine Creation"/>
<br />
<br />
Click "login" and create a Broadcom account:  <br/>
<img src="https://imgur.com/PUg5cZp.png" height="80%" width="80%" alt="Virtual Machine Creation"/>
<br />
<br />
Once logged in select Software -> Mainframe Software -> My Dashboard : <br/>
<img src="https://imgur.com/YeGvBN0.png" height="80%" width="80%" alt="Virtual Machine Creation"/>
<br />
<br />
On the next screen select "My downloads":  <br/>
<img src="https://imgur.com/9Z7nFzF.png" height="80%" width="80%" alt="Virtual Machine Creation"/>
<br />
<br />
Click on "here":  <br/>
<img src="https://imgur.com/w8nWMG9.png" height="80%" width="80%" alt="Virtual Machine Creation"/>
<br />
<br />
Find "VMware Workstation Pro 17" and click on it:  <br/>
<img src="https://imgur.com/YpEZEH3.png" height="80%" width="80%" alt="Virtual Machine Creation"/>
<br />
<br />
Click on "VMware Workstation Pro 17.0 for Windows" and select the newest version:  <br/>
<img src="https://imgur.com/52bV0Iw.png" height="80%" width="80%" alt="Virtual Machine Creation"/>
<br />
<br />
After, check the terms and conditions box, next click the download button and fill out the additional verification
<img src="https://imgur.com/rPLPPEP.png" height="80%" width="80%" alt="Virtual Machine Creation"/>
<br />
<br />
Once installed, launch the installer and keep all default settings and click finish
<img src="https://imgur.com/tV2hYQz.png" height="80%" width="80%" alt="Virtual Machine Creation"/>
<br />
<br />
After downloading the software open the VMware Workstation application and click on "Create a New Virutal Machine"
<img src="https://imgur.com/ufet22u.png" height="80%" width="80%" alt="Virtual Machine Creation"/>
</p>
